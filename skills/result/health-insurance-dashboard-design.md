## 七、数据口径与更新说明

### 指标定义

| 指标 | 计算公式 | 数据来源 | 更新频率 |
|------|---------|---------|---------|
| 规模保费 | 全部保单保费合计（含分出） | 核心系统 | T+1 |
| 原保费收入 | 规模保费 - 分出保费 | 财务系统 | T+1 |
| 已赚保费 | 原保费收入 - 未到期责任准备金提转差 | 精算系统 | 月度 |
| 综合成本率 | （已发生赔款 + 费用）/ 已赚保费 | 财务系统 | 月度 |
| 赔付率 | 已发生赔款 / 已赚保费 | 财务+理赔 | 月度 |
| 费用率 | （手续费佣金 + 管理费 + 税金）/ 已赚保费 | 财务系统 | 月度 |
| 结案率 | 已决件数 / （已决 + 未决）件数 | 理赔系统 | T+1 |
| 市场份额 | 本公司保费 / 市场总保费 | 监管披露 | 月度 |
| 续期率（13M） | 13个月前生效保单中按时缴费的比例 | 核心系统 | 月度 |

### 市场数据来源优先级

| 来源 | 时效性 | 可靠性 | 可获得性 |
